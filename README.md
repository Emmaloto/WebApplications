## 🔗 Linked Title Text for URL

Check out what [this app](https://emmaloto.github.io/apps/WebApplications/replaceURLContent) does! I made it because I wanted to copy **YouTube** links to my document files with more information, and Google Docs didn't always give me the helpful popup to replace the linked text with the page title.

Note: This is in PHP so needs to be run server-side.

## 📄 Sorting Transactions

I wanted a quick way to sort some transactions  This project also includes a web application for sorting transactions. It allows the user to upload a CSV file of transactions and a mapping CSV file. The application then classifies the transactions based on the mapping and provides the output as a new CSV file. The application is built with HTML, CSS, and JavaScript.
