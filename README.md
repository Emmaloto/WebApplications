## 🔗 Linked Title Text for URL
Check out what [this app](https://emmaloto.github.io/apps/WebApplications/replaceURLContent) does! I made it because I wanted to copy **YouTube** links to my document files with more information, and Google Docs didn't always give me the helpful popup to replace the linked text with the page title.
